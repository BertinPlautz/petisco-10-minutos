# Petisco de 10 Minutos — Simbas Pet

Landing page oficial do guia **Petisco de 10 Minutos** (50 receitas caseiras + 3 bônus), publicada em `https://www.simbaspet.com.br`.

## Conteúdo
- `index.html` — Landing page estática mobile-first com 3 módulos interativos (Raio-X do Rótulo, Calculadora Anual e Espiada de Receita), zero dependências externas.
- `img/` — Fotografias editoriais otimizadas em WebP (`< 111 KB` cada) + `og.jpg` (`1200×630`).
- `vercel.json` — Configuração de URLs limpas e cache imutável para imagens.
